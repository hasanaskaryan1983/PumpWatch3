# Risk disclosure (in-app + store)

1. Meme coins and low-liquidity tokens can go to zero in minutes.
   The Rug Safety score is a risk indicator, NOT a guarantee of safety.
   "UNKNOWN" always means "we could not check", never "safe".
2. Every signal shows confidence, evidence and an invalidation level.
   A signal without those three is a bug — report it.
3. Historical accuracy of similar signals is displayed where sample size
   allows; small samples are labeled as such. Past ≠ future.
4. Paper trading uses simulated fills with fees & slippage; real exchange
   results will differ.
5. This app is non-custodial: it never asks for exchange withdrawal
   permission, API keys, or seed phrases. Anyone asking for those in our
   name is an impersonator.
6. Nothing in this app is financial advice.
