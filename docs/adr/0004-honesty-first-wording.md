# ADR-0004: سیاست متن صادقانه در UI

Status: Accepted (Commits 116, 118, 140)

## Context
متن‌های قبلی ادعاهای نادرست داشتند: «هوش مصنوعی»، «هر ۶ ساعت»، «۱۲ چک امنیتی»، «۵۰ تریدر برتر دنیا». این هم اعتماد کاربر را می‌شکست هم ریسک حقوقی داشت.

## Decision
- هر عدد یا ادعا در UI باید به کد ارجاع‌پذیر باشد (مثلاً بازهٔ مانیتور = «هر ۳۰ دقیقه» مطابق MonitorWorker)
- استفاده از واژه‌های AI/ML برای سیگنال‌دهی ممنوع (همه لایه‌ها قاعده‌محورند)
- سلب‌مسئولیت‌ها صریح: «همبستگی ≠ علیت»، «این اپ توصیهٔ مالی نیست»
- متن‌های کلیدی با تست UI قفل شده‌اند: HonestyScreensUiTest (Commit 140)

## Consequences
+ اعتماد کاربر و کاهش ریسک حقوقی
+ رگرسیون متن‌ها توسط CI گرفته می‌شود (اگر کسی ادعای دروغین برگرداند، CI قرمز می‌شود)
- لحن بازاریابی اپ محدودتر است (انتخاب آگاهانه)
